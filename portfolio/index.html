Multiple test layers.

Each layer has a defined risk, executable source, reference environment, and expected evidence.

02

Delivery pipeline

From change to inspectable evidence.

  1. 1
    Verify

    Secrets, whitespace, versions, TypeScript, traceability, audit, and deterministic Chromium gate.

  2. 2
    Exercise

    Smoke, network, mobile, and the Chromium–Firefox–WebKit compatibility matrix in Docker.

  3. 3
    Parallelize

    Regression shards execute independently and merge into a single Playwright report.

  4. 4
    Publish

    Curated screenshots, traces, HTML reports, and this static evidence site become reviewable artifacts.
